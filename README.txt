- assets/logo.png Existing SCS logo
- assets/ivan.jpg Existing CEO image

HOW TO PREVIEW
1. Open index.html in a browser.
2. For the most accurate local preview, run a simple local server from this folder:
   python -m http.server 8000
3. Then browse to http://localhost:8000

DEPLOYMENT NOTES
- This version is framework-free and can be hosted on almost any web server.
- The quote form currently opens the visitor's email application with the form data prefilled.
- During production deployment, the form can be connected to WordPress, Formspree, HubSpot, a CRM, or a server-side form handler.
- The "Our Work" project images are intentionally custom CSS placeholders. Replace those blocks with real SCS project photography for the strongest final result.
- Contact information and testimonials are based on the current SCS website.
